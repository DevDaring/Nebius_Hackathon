Self-hosted fonts for NemoTwins (no third-party font requests at runtime).

Plus Jakarta Sans (variable, weight 200-800; Latin + Latin Extended, upright and italic)
  Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans)
  Licence: SIL Open Font License 1.1 -> OFL-PlusJakartaSans.txt

The woff2 subsets were taken unmodified from the @fontsource-variable/plus-jakarta-sans 5.3.0 npm package.
Latin + Latin Extended cover English, Spanish, French, German and Italian. Japanese uses the
operating system's CJK fonts (see the :lang(ja) font stack in src/index.css); no CJK font is bundled.
@font-face rules live in src/index.css.
